# CareerPilot 数据目录

## knowledge/ —— 知识库（会被灌入向量库）

按主题分四个子目录，共 9 篇、约 2 万字，切分后 75 个片段。

| 目录 | 内容 |
|---|---|
| `resume/` | 简历结构、人岗匹配、项目经历写法 |
| `interview/` | 面试准备流程、技术面高频问题、行为面与 STAR |
| `job/` | AI 应用开发技能图谱、JD 解读与匹配度评估 |
| `process/` | 投递策略与节奏、谈薪与 offer 决策 |

`config/chroma.yml` 的 `data_path` 指向本目录，启动时自动增量加载（MD5 去重）。
新增文档后点侧边栏「重建全部向量」即可生效。

## 根目录 —— 示例数据（不进知识库）

- `candidate_resume.txt`：脱敏的示例候选人简历，被 `seed_demo_data.py` 读取，用于填充候选人资料。
- `jobs.json`：示例岗位，覆盖高匹配、部分匹配和低匹配场景。
- `job_search_guide.txt`：早期的简化版求职知识，已被 `knowledge/` 下的文档取代，保留作为历史示例。

这些示例数据不包含真实个人信息或真实招聘公司的内部资料。

**注意**：示例简历曾经和知识文档放在同一目录，导致被当作知识灌入，检索时会命中「姓名：林默（示例数据）」这类内容，污染回答。现在通过 `data_path` 隔离到 `knowledge/` 子目录解决。
